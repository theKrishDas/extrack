## Dependencies

This resizable panel has 2 dependencies. Install them with your desired package manager. Also don't forget to install `class-variance-authority` and `clsx` aswell (you might already have it).

```sh
bun add motion react-use-measure
```

- [`react-use-measure`](https://www.npmjs.com/package/react-use-measure): to calculate the height of the children
- [`motion`](https://www.npmjs.com/package/motion): to animate stuff ofc!
