## Dependencies

This button-component has couple of very light-weight dependencies. Install them
with your desired package manager. Also don't forget to install
`class-variance-authority` and `clsx` aswell (you might already have it).

```sh
bun add react-aria-components @react-aria/utils @radix-ui/react-slot motion
```

- [`react-aria-components`](https://www.npmjs.com/package/react-aria-components):
  Unpacked Size: **4.01 MB**
- [`@react-aria/utils`](https://www.npmjs.com/package/@react-aria/utils):
  Unpacked Size: **766 kB**
- [`@radix-ui/react-slot`](https://www.npmjs.com/package/@radix-ui/react-slot):
  Unpacked Size: **32.3 kB**

- [`motion`](https://www.npmjs.com/package/motion): We need this to animate
