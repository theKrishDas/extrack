## Dependencies

This button-component has couple of very light-weight dependencies. Install them
with your desired package manager. Also don't forget to install
`class-variance-authority` and `clsx` aswell (you might already have it).

```sh
bun add @react-aria/button @react-aria/focus @react-aria/interactions @react-aria/utils @radix-ui/react-slot motion
```
